NEXUS GAMING - Reborn V1.0

Open index.html in Chrome, Edge, or another modern browser.
The site works as static HTML/CSS/JavaScript, with responsive mobile and desktop layouts.

FILES
index.html - website structure
style.css - all styling and responsive layouts
script.js - navigation, PC builder, contact demo
assets/pic - all 18 original images
assets/video/1.mp4 - original video

NOTES
- The PC builder is a demonstration, not a compatibility checker or price quotation.
- Contact form opens an email draft without a preset recipient. No message is stored or sent by this site.
- Google Fonts require an internet connection; fallback fonts work offline.
- Original local D: paths have been replaced with relative paths.
- You can upload the folder contents to GitHub Pages to publish the static site.
